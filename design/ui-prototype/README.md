# 《土豆大冒险》(Potato Adventure) 界面交互原型与设计规范落地报告

本文档为《土豆大冒险》前端 UI 原型的完整交付说明。该原型严格依据 `/home/Yuhang/potato-adventure/firstmate/data/potato-frontend-design-a1/report.md` 中的 **Part C（完整前端 UI 架构设计规范）** 落地，采用《泰拉瑞亚》复古像素艺术风格，以纯离线、零构建、零网络依赖的标准制作。

---

## 1. 原型运行与快速打开指南

### 1.1 打开方式
- **单一入口**：直接用任意现代网页浏览器（Chrome / Edge / Firefox / Safari）打开本地文件：
  ```
  design/ui-prototype/index.html
  ```
- **支持协议**：直接通过 `file://` 协议打开（例如双击文件或在浏览器中打开 `file:///.../design/ui-prototype/index.html`）。
- **零依赖承诺**：
  - 不需要启动任何本地 HTTP 服务器（如 `python -m http.server`、`nginx`、`node` 等）；
  - 不需要任何前端构建步骤（无需 `npm install`、`webpack`、`vite`）；
  - 不需要连接外网（100% 离线自包含，代码中无任何 `http://`、`https://`、CDN 或远程字体引用）。

### 1.2 视口与分辨率基准
- 基准渲染尺寸：**1280 × 720**（标准 16:9 像素等比防形变视口）。
- 全程采用 `image-rendering: pixelated` / `crisp-edges`，硬边缘邻近采样渲染，杜绝任何半像素插值模糊。

## 4. 与 Part C 设计规范的对照与演进说明

在严格遵守 Part C 核心架构（1280×720 分辨率、状态机流转、配色调色板、实体属性体系）的基础上，本原型在以下几处进行了符合现代前端用户体验与展示效果的工程微调：

1. **字体离线嵌入方案 (Typography Fallback Evolution)**:
   - *Part C 原始建议*：建议引入 `Zpix` 或 `Fusion Pixel Font`。
   - *本次实现演进*：考虑到交付物必须保证在断网、未安装本地字体、纯 `file://` 打开的环境下 100% 具备全部汉字覆盖率，本原型本地直接打包了开源经典的 **GNU Unifont (`unifont.otf`)**，并配置了优雅的像素/等宽回退栈（`monospace`, `WenQuanYi`, `PingFang SC`, `Microsoft YaHei`）。这确保了从生僻字到游戏专属道具名均呈现锐利无毛刺的纯正像素风。
2. **三色地貌无缝切换 (Triple Biome Showcase)**:
   - *Part C 原始建议*：大地图仅规划了单一套平原草地。
   - *本次实现演进*：为了让评审人直观体验不同游戏阶段的氛围，原型在大地图 HUD 顶部提供了【平原村庄】、【迷雾森林】、【暗黑地牢】三大地貌的即时切换。切换地貌时，不仅背景图块完全改变，环境粒子系统（日光落叶 / 迷雾孢子 / 地牢火把微粒）与驻留实体（村长、铁匠、迷雾怪、暗影守卫）也会同步切换。
3. **战斗系统全流程可玩性强化 (Interactive Battle Polish)**:
   - *Part C 原始建议*：定义了 4 张指令卡与时间轴。
   - *本次实现演进*：原型实现了真实的回合交替驱动状态机：点击普攻或技能后，触发玩家攻击前冲动画、音效播放、敌方受击震颤闪白、红/黄暴击抛物线跳字（`-42 HP`）、右侧战报窗口追加富文本日志；随后自动移交行动权给敌方 AI，敌方发动还击，扣减我方血条；战斗结束时弹出品质战利品结算模态框或转入战败画面。
4. **离线 8-Bit 声音合成器 (Procedural Web Audio Engine)**:
   - 原型引入了纯代码构建的 `AudioEngine`（基于原生 Web Audio API 的方波、三角波、带通白噪声生成器），在鼠标悬停按键、点击确认、刀剑挥砍、火球爆发、受击扣血时产生逼真的 8-Bit 复古音效，彻底避免了外部音频资源丢失的隐患。
