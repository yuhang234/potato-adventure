# 土豆冒险游戏 - 项目需求文档（增强版 V2.0）
## 项目概述
**项目名称**: 土豆冒险 (Potato Adventure)
**项目类型**: Java桌面冒险游戏
**开发周期**: 8-10周（分4个迭代阶段）
**技术栈（细化版）**:
- 核心编程语言：Java SE 8（LTS长期支持版，Oracle JDK 8/OpenJDK 8实现）
- 界面开发：JavaFX 8（8u401，稳定版，替代Swing，Oracle JDK 8内置/OpenJDK 8需单独适配）
- 构建工具：Maven 3.6.3（主选）/ Gradle 7.6.4（备选）
- 依赖管理：Maven Central仓库 / Gradle Maven仓库
- 数据存储：
  - 本地存档：SQLite 3.45.0 + JDBC驱动（org.xerial:sqlite-jdbc:3.45.0，兼容Java 8）
  - 配置文件：Jackson 2.16.1（处理JSON序列化/反序列化，兼容Java 8）
- 游戏资源处理：
  - 图形生成：JavaFX GraphicsContext + BufferedImage（纯代码生成）
  - 音效生成：Java Sound API（javax.sound.sampled）+ Tritonus库（扩展音效格式支持）
- 版本控制：Git 2.43.0 + GitHub/GitLab（代码托管）
- 开发工具：
  - IDE：IntelliJ IDEA 2025.1（Ultimate版，支持JavaFX可视化开发）
  - 代码检查：CheckStyle 10.16.0 + PMD 7.0.0
  - 测试工具：JUnit 4.13.2（单元测试，适配Java 8）+ TestFX 3.1.0（JavaFX UI测试，兼容Java 8）
  - 性能分析：VisualVM 2.1.6（内存/CPU监控）
- 打包工具：Launch4j + Inno Setup（Windows）/ AppBundler（Mac）/ sh脚本+deb/rpm（Linux）（Java 8第三方打包方案）
- 辅助工具：
  - UML建模：StarUML 6.1（架构设计）
  - 版本管理：GitKraken（可视化Git操作）
  - 文档编写：Markdown（本文档）+ Confluence（团队协作文档）
**目标用户**: 休闲游戏玩家、Java程序设计学习者
**项目定位**: 轻量级、可扩展、纯代码生成资源的开源Java游戏学习项目

## 一、核心功能模块（完善版）
### 1.1 游戏世界系统
#### 1.1.1 地图系统
- **多层地图设计**: 支持5个核心场景（森林、沙漠、雪山、洞穴、城镇）+ 1个随机地牢场景
  - 场景切换无缝衔接，加载时间≤2秒
  - 每个场景包含至少3个子区域（如森林分为：新手区、密林、BOSS巢穴）
- **地图元素**:
  - 可通行区域与障碍物：障碍物支持碰撞检测（像素级精准）
  - 传送点/入口：带加载动画，支持跨场景传送
  - 交互式物品：宝箱（随机掉落）、NPC（带对话）、道具（可拾取）
  - 环境危险区域：岩浆（持续掉血）、陷阱（触发后眩晕/减速）
- **小地图显示**:
  - 实时显示玩家坐标、已探索区域、关键地标
  - 支持缩放、透明度调节（0-100%）
- **迷雾系统**:
  - 未探索区域显示半透明黑色迷雾，探索后永久清除
  - 迷雾边缘有渐变效果，避免视觉割裂
- **地图编辑器**:
  - 可视化编辑界面，支持拖拽放置地图元素
  - 地图文件导出/导入（JSON格式）
  - 支持地图预览、碰撞检测校验

#### 1.1.2 天气与时间系统
- **昼夜循环**:
  - 游戏内1小时 = 现实2分钟，可在设置中调整倍率
  - 昼夜影响：夜晚怪物攻击力+10%，NPC商店关闭
- **天气变化**:
  - 随机触发（晴天70%、雨天20%、雪天10%）
  - 天气效果：雨天移动速度-15%，雪天视野范围缩小，晴天资源掉落率+5%
- **季节系统**:
  - 游戏内7天 = 1个季节，四季循环
  - 季节影响：春季资源刷新加速，夏季怪物活跃度提升，秋季掉落率增加，冬季部分区域结冰（可通行）

### 1.2 角色系统
#### 1.2.1 玩家角色
- **多角色选择**: 5个初始角色（土豆勇士、土豆法师、土豆游侠、土豆工匠、土豆商人）
  - 每个角色有专属初始技能和属性偏向
- **角色属性**:
  | 属性类型 | 具体属性 | 作用说明 |
  |----------|----------|----------|
  | 基础属性 | HP/MP    | 生命值/魔法值，归0则角色死亡 |
  |          | 攻击力   | 影响普通攻击/技能伤害 |
  |          | 防御力   | 减免受到的伤害 |
  |          | 速度     | 影响移动/攻击频率 |
  | 扩展属性 | 暴击率   | 触发双倍伤害概率（0-100%） |
  |          | 闪避率   | 躲避攻击概率（0-100%） |
  |          | 经验值/等级 | 等级提升解锁技能/属性 |
  | 特殊属性 | 饥饿度   | 低于20%移动速度降低，归0持续掉血 |
  |          | 体力值   | 影响奔跑/技能释放次数 |
  |          | 幸运值   | 提升掉落稀有物品概率 |
- **角色成长**:
  - 等级上限50级，每级获得2个自由属性点+1个技能点
  - 等级提升有动画特效+属性提示
  - 支持属性重置（消耗钻石道具）
- **外观自定义**:
  - 装备外观独立显示（武器/防具/饰品）
  - 支持角色染色（16种基础颜色+自定义色值）

#### 1.2.2 NPC系统
- **友好NPC**:
  - 村民：提供主线/支线任务，好感度≥80解锁隐藏任务
  - 商人：根据好感度调整物价（最低8折）
  - 导师：教授技能，高好感度解锁稀有技能
  - 铁匠：装备强化/修理，高好感度降低强化成本
- **NPC对话系统**:
  - 多分支对话（至少3个选项），影响好感度/任务走向
  - 好感度等级：陌生→友好→亲密→崇敬→崇拜
  - 随机事件：每日触发1次特殊对话，可获得额外奖励
- **NPC AI**:
  - 日常行为：村民白天工作、夜晚休息，商人定时补货
  - 环境响应：雨天NPC会躲雨，雪天会增加保暖动作

### 1.3 战斗系统
#### 1.3.1 战斗模式
- **实时战斗**: ARPG风格，支持键鼠/手柄操作
- **回合制战斗**: 可在设置中切换，每回合30秒操作时间
- **混合模式**: 野外实时战斗，副本/BOSS战自动切换为回合制

#### 1.3.2 战斗机制
- **基础攻击**:
  - 普通攻击：无消耗，冷却1秒
  - 重击：消耗5%体力，伤害×1.5，冷却3秒
  - 连击：连续3次普通攻击触发，伤害×2
- **技能系统**:
  - 主动技能：15个基础技能+8个职业专属技能
    - 技能分类：伤害型、治疗型、控制型、辅助型
    - 技能冷却：5-30秒不等，消耗MP/体力
  - 被动技能：10个通用被动+5个职业被动
  - 组合技：特定技能顺序释放触发（如“火球+冰锥=冰火两重天”）
- **战斗状态**:
  | 状态类型 | 具体效果 | 持续时间 |
  |----------|----------|----------|
  | 增益     | 攻击提升+20% | 30秒 |
  |          | 防御提升+30% | 45秒 |
  |          | 加速+25% | 20秒 |
  | 减益     | 中毒（每秒掉5%HP） | 15秒 |
  |          | 冰冻（无法移动） | 5秒 |
  |          | 眩晕（无法操作） | 3秒 |
  |          | 灼烧（每秒掉8%HP） | 10秒 |
  |          | 流血（每秒掉3%HP） | 20秒 |
- **战斗评分**:
  - 评分标准：通关时间、受击次数、技能使用率
  - 评分等级：S(≥90)、A(80-89)、B(70-79)、C(60-69)、D(<60)
  - S级评分额外掉落稀有道具

#### 1.3.3 敌人系统
- **怪物类型**:
  - 普通怪物：20种（分近战/远程/辅助）
  - 精英怪物：8种（属性×2，带1个特殊技能）
  - Boss怪物：8个（多阶段战斗，每个阶段有专属技能）
  - 隐藏Boss：2个（需完成前置任务/达成特定条件解锁）
- **怪物AI**:
  - 近战怪物：优先追击玩家，血量<30%会逃跑/召唤同伴
  - 远程怪物：保持距离输出，血量<50%会使用闪避/护盾
  - 辅助怪物：优先治疗同伴，被攻击后切换为防御模式
- **怪物生成**:
  - 固定刷新点：每5分钟刷新1次
  - 随机遇敌：野外移动有10%概率触发，可通过道具屏蔽
  - 特殊事件：节日/季节活动召唤限定怪物

### 1.4 物品与装备系统
#### 1.4.1 物品分类
| 物品类型 | 具体内容 | 获取方式 |
|----------|----------|----------|
| 消耗品   | 恢复道具 | 商店购买/怪物掉落/采集 |
|          | 增益道具 | 制作/活动奖励 |
|          | 特殊道具 | 任务奖励/BOSS掉落 |
| 任务物品 | 任务专属道具 | 任务过程中获取 |
| 材料     | 基础材料 | 采集/分解装备 |
|          | 稀有材料 | BOSS掉落/活动奖励 |
| 货币     | 金币     | 任务/战斗/出售物品 |
|          | 钻石     | 充值/成就奖励/隐藏任务 |
|          | 荣誉点   | PVP战斗/竞技场 |
|          | 公会贡献 | 公会任务/公会战 |

#### 1.4.2 装备系统
- **装备部位**: 武器、头盔、盔甲、护腿、鞋子、戒指（2个）、项链、手镯（2个）
- **装备品质**:
  | 品质 | 颜色 | 掉落概率 | 属性加成 |
  |------|------|----------|----------|
  | 普通 | 白色 | 60%      | 基础属性+5% |
  | 优秀 | 绿色 | 25%      | 基础属性+10% |
  | 精良 | 蓝色 | 10%      | 基础属性+15% + 1个附加属性 |
  | 史诗 | 紫色 | 3%       | 基础属性+20% + 2个附加属性 |
  | 传说 | 橙色 | 1.5%     | 基础属性+30% + 3个附加属性 |
  | 神话 | 红色 | 0.5%     | 基础属性+50% + 4个附加属性 + 专属技能 |
- **装备属性**:
  - 基础属性：固定加成（如攻击力+50）
  - 附魔属性：随机生成（如暴击率+5%）
  - 套装效果：收集2/4/6件同套装触发额外加成
- **装备强化**:
  - 强化等级：+0 ~ +15
  - 强化概率：+1~+5 100%，+6~+10 80%~20%，+11~+15 10%~1%
  - 强化保护：使用保护符可避免强化失败降级
  - 装备精炼：消耗材料提升品质（最多提升2级）
  - 宝石镶嵌：每件装备3-5个孔位，宝石可升级/拆卸

#### 1.4.3 背包系统
- **容量管理**: 初始50格，可通过道具扩展至200格（每扩展10格消耗1个扩容道具）
- **物品分类**: 自动分类（消耗品/装备/材料/任务物品）
- **快捷栏**: 10个快捷键位（数字键1-0），支持拖拽设置
- **物品排序**: 支持按类型、品质、等级、获得时间排序
- **物品锁定**: 锁定后无法出售/分解/丢弃，需解锁密码

### 1.5 任务系统
#### 1.5.1 任务类型
| 任务类型 | 数量 | 奖励重点 | 刷新机制 |
|----------|------|----------|----------|
| 主线任务 | 30个 | 经验、技能点、剧情解锁 | 完成前置解锁 |
| 支线任务 | 50+  | 金币、材料、好感度 | 等级/场景解锁 |
| 日常任务 | 10种 | 金币、经验、日常宝箱 | 每日5点刷新 |
| 成就任务 | 80+  | 成就点、称号、钻石 | 达成条件解锁 |
| 悬赏任务 | 20种 | 荣誉点、稀有材料 | 每2小时刷新 |
| 连锁任务 | 10套 | 套装装备、隐藏技能 | 完成首任务解锁 |
| 限时活动 | 随节日 | 限定道具、称号 | 活动期间有效 |

#### 1.5.2 任务机制
- **任务追踪**: 最多同时追踪5个任务，显示进度（如“击杀10/20只史莱姆”）
- **任务导航**: 自动寻路到任务目标点（支持关闭）
- **任务奖励**:
  - 基础奖励：经验、金币
  - 额外奖励：装备、道具、技能点、属性点
  - 特殊奖励：称号、成就点、稀有材料
- **任务日志**: 记录已完成/进行中/失败的任务，支持搜索/筛选

### 1.6 社交系统
#### 1.6.1 好友系统
- **好友列表**: 最多添加50个好友，支持分组管理
- **在线状态**: 显示在线/离线/游戏中/离开
- **好友聊天**: 支持文字+表情，消息实时推送
- **组队邀请**: 最多5人组队，组队后经验+20%
- **好友度系统**: 互动（组队/赠送礼物）提升好感度，解锁专属称号/奖励

#### 1.6.2 聊天系统
- **频道分类**: 世界、区域、队伍、私聊、公会、系统
  - 世界频道：冷却10秒，可屏蔽
  - 系统频道：仅显示系统通知，不可发送
- **聊天功能**:
  - 文字聊天：支持换行、表情
  - 物品链接：点击可查看物品详情
  - 坐标分享：点击可自动导航
- **敏感词过滤**: 屏蔽违规词汇，支持自定义屏蔽列表

#### 1.6.3 公会/团队系统
- **公会创建**: 需等级≥20，消耗10万金币，最多50人
- **公会管理**: 会长/副会长/长老/成员权限分级
  - 会长：可转让/解散公会，设置权限
  - 副会长：可审批加入、踢除成员
- **公会仓库**: 共享存储，按权限提取/存入
- **公会任务**: 每日5个，完成后获得公会贡献
- **公会战**: 每周六开启，5v5对战，奖励公会资金/稀有道具
- **公会技能**: 升级公会解锁，全体成员共享（如攻击力+5%）

### 1.7 经济系统
#### 1.7.1 货币系统
| 货币类型 | 获取方式 | 主要用途 |
|----------|----------|----------|
| 金币     | 任务、战斗、出售物品 | 购买普通道具/装备、强化装备 |
| 钻石     | 充值、成就、隐藏任务 | 购买稀有道具、重置属性、扩展背包 |
| 荣誉点   | PVP、悬赏任务 | 兑换PVP专属装备/称号 |
| 公会贡献 | 公会任务、公会战 | 兑换公会仓库道具、升级公会技能 |

#### 1.7.2 交易系统
- **NPC商店**:
  - 杂货店：出售消耗品、基础材料
  - 装备店：出售普通/优秀品质装备
  - 特殊商店：出售稀有道具（需特定货币）
- **拍卖行**:
  - 玩家寄售：上架物品需缴纳1%手续费
  - 竞拍系统：最低加价10%，竞拍时间1-24小时
  - 一口价：支持设置直接购买价格
- **面对面交易**: 需双方确认，交易后无法撤销
- **价格波动**: 稀有物品根据近期交易量调整价格（±20%）

- **大师级**: 技能≥80级可晋升大师，制作物品品质+1级

### 1.9 成就与收集系统
#### 1.9.1 成就系统
- **成就分类**: 战斗、探索、收集、社交、生活、隐藏
- **成就点数**: 累计点数解锁成就等级（青铜→白银→黄金→铂金→钻石）
- **成就称号**: 解锁后可在角色头顶显示，部分称号带属性加成
- **隐藏成就**: 需达成特殊条件（如“无伤击杀BOSS”），奖励稀有道具

#### 1.9.2 图鉴系统
- **怪物图鉴**: 记录遇到的怪物属性、掉落、弱点
- **物品图鉴**: 记录获得过的物品，支持筛选/搜索
- **地图图鉴**: 记录探索进度、地标位置

## 三、技术实现要求（完善版）
### 3.1 架构设计
#### 3.1.1 核心架构
- **MVC架构**:
  - Model：游戏数据（角色、地图、物品）
  - View：UI界面、图形渲染
  - Controller：用户输入、逻辑处理
- **模块划分**:
  ```
  com.potatoadventure/
  ├── core/          # 核心引擎（游戏循环、渲染、输入）
  ├── model/         # 数据模型（角色、地图、物品）
  ├── view/          # 界面渲染（UI、图形）
  ├── controller/    # 控制器（输入处理、逻辑）
  ├── service/       # 业务服务（战斗、任务、经济）
  ├── util/          # 工具类（图形生成、数据存储）
  └── config/        # 配置文件
  ```

#### 3.1.2 设计模式
| 模式名称 | 应用场景 |
|----------|----------|
| 单例模式 | 游戏管理器、资源管理器 |
| 工厂模式 | 角色/怪物/物品创建 |
| 观察者模式 | 事件系统（战斗、任务） |
| 状态模式 | 游戏状态（菜单/战斗/探索） |
| 策略模式 | 战斗AI、技能释放 |
| 装饰器模式 | 装备属性加成 |
| 原型模式 | 物品/怪物克隆 |

### 3.2 数据存储
- **配置文件**: JSON格式存储游戏配置（角色属性、怪物数据、物品配方）
- **存档文件**: SQLite数据库存储玩家存档（角色数据、进度、物品）
- **资源管理**:
  - 统一资源加载器，支持懒加载
  - 资源缓存机制，避免重复生成
  - 资源释放策略，低内存时自动清理

### 3.3 性能优化
- **对象池**: 复用频繁创建的对象（子弹、特效、怪物）
- **懒加载**: 按需加载地图、资源，避免初始加载过慢
- **多线程**:
  - 主线程：UI渲染、输入处理
  - 后台线程：数据加载、存档、网络请求
- **内存管理**:
  - 及时释放无用资源（如离开场景后释放地图资源）
  - 限制对象数量（如屏幕内怪物数量≤20）
- **渲染优化**:
  - 视口裁剪，只渲染可见区域
  - 批量渲染，减少绘制调用

### 3.4 扩展性设计
- **插件系统**: 支持Mod扩展（新增角色/地图/任务）
- **配置驱动**: 核心参数通过配置文件调整（无需修改代码）
- **版本兼容**: 存档支持跨版本兼容
- **模块化开发**: 各系统独立，便于扩展/修改

### 3.5 代码规范
- **命名规范**:
  - 类名：PascalCase（如PlayerCharacter）
  - 方法/变量：camelCase（如playerHealth）
  - 常量：UPPER_SNAKE_CASE（如MAX_LEVEL）
- **注释规范**:
  - 类/方法添加JavaDoc注释
  - 复杂逻辑添加行注释
  - 关键代码添加变更记录
- **代码检查**: 使用CheckStyle/PMD进行代码质量检查

### 3.6 版本控制
- **分支策略**:
  - main：稳定版本
  - develop：开发分支
  - feature/*：功能分支
  - bugfix/*：修复分支
- **提交规范**:
  ```
  type(scope): message
  # type: feat/fix/docs/style/refactor/test/chore
  # example: feat(battle): 添加连击系统
  ```

## 四、美术与音效要求（完善版）
### 4.1 图形资源生成（纯代码）
#### 4.1.1 技术规范
- **核心技术**: JavaFX GraphicsContext + BufferedImage
- **像素标准**:
  - 角色/怪物：32×32（Boss 64×64）
  - 地图块：32×32
  - UI元素：按比例适配（支持缩放）
- **颜色规范**:
  - 使用统一颜色常量类，避免硬编码
  - 支持主题切换（亮色/暗色）

#### 4.1.2 图形生成优化
- **缓存机制**: 生成的图形缓存到内存，避免重复计算
- **批处理生成**: 初始化时批量生成基础图形
- **动态调整**: 支持分辨率适配，图形自动缩放

### 4.2 音效系统
#### 4.2.1 音效类型
| 音效类别 | 数量 | 生成方式 |
|----------|------|----------|
| UI音效   | 15+  | Java Sound API生成 |
| 战斗音效 | 20+  | Java Sound API生成 |
| 环境音效 | 10+  | 混合生成（基础音+特效） |
| 背景音乐 | 8+   | 简单MIDI音乐 |

#### 4.2.2 音效实现
- **音效管理器**: 统一管理音效播放、音量、循环
- **空间音效**: 支持左右声道（如左侧怪物声音从左声道播放）
- **音效优先级**: 重要音效（如技能释放）优先于环境音效

### 4.3 动画系统
- **帧动画**: 角色行走/攻击/技能动画（4-8帧）
- **过渡动画**: 场景切换、UI弹窗、等级提升
- **粒子特效**: 技能释放、爆炸、回血效果
